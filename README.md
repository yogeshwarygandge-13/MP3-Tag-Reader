MP3 Tag Reader

A C-based application that reads and displays metadata from MP3 audio files.

Features
- Extract song title
- Read artist name
- Display album information
- Retrieve release year
- Identify music genre

Technologies Used
- C Programming
- File Handling
- Structures
- String Manipulation
- GCC Compiler

Project Purpose
To understand MP3 file structure and learn how to extract metadata using C programming.
